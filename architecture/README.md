# Архитектура проекта СМ7

Программа прогнозирует задержки трёх направлений через 60 минут и выбирает минимальную. Шаг данных — 15 минут, вход — восемь наблюдений по трём задержкам.

## Запуск

В Windows дважды нажмите **START.cmd**: скрипт проверяет среду Python 3.12, подготавливает зависимости и открывает графическое окно. Первый запуск может потребовать интернет. В Ubuntu и Windows доступны команды из каталога `architecture`:

```bash
python run.py status
python run.py validate
python run.py prepare
python run.py verify-model
python run.py gui
python -m unittest discover -s tests -v
```

Проверка и подготовка данных работают без сторонних библиотек. Они используют единственный датасет [traffic_delays.csv](../data-project/traffic_delays.csv) и его карту происхождения. `prepare` проверяет формирование окон и выводит размеры массивов, не создавая дублей CSV.

GRU реализована в `model.py`: 8 × 3 на входе, 3 неотрицательные задержки в минутах на выходе. Техническая проверка выполняет один шаг обучения на фиксированных тензорах и проверяет сохранение/загрузку весов в памяти. Она не доказывает качество прогноза.
