# Архитектура проекта СМ7

Программа должна выбирать один из трёх светофоров по истории плотности потока за последний час. Здесь собраны архитектура, обоснование модели и запускаемый каркас. Основа — версия 2 ТЗ, переданная 25 ноября 2026 года.

## Начать работу

В Windows дважды нажмите **START.cmd**. Откроется окно с кнопками. Среда Python 3.12 и необходимые библиотеки проверяются автоматически. На этом ПК компоненты уже установлены в `.venv`. При первом запуске на другом Windows ПК программа скачает недостающие компоненты; для этого нужен интернет. Последующие запуски с исправной средой не обращаются в сеть.

В окне доступны проверка GRU, объяснение выбора модели, схема и состояние проекта. Проверка выполняет один технический шаг обучения и проверяет сохранение и загрузку весов в памяти. Она не использует дорожные данные и не создаёт обученную модель проекта.

Схему можно открыть и отдельно: [docs/overview.html](docs/overview.html).

В Ubuntu или из терминала Windows:

```text
python run.py
python run.py architecture
python run.py model
python run.py status
python run.py status --json
python run.py gui
python run.py verify-model
```

В Ubuntu команда интерпретатора может называться `python3`.

Сейчас работают окно с кнопками, консольное меню, материалы, GRU и её техническая проверка. Генерация, подготовка данных, обучение на полном наборе, оценка и рабочий прогноз ещё не подключены. Команды этих режимов возвращают объяснение и код 2. В окне недоступные действия подписаны и отключены.

## Границы текущей работы

Сбор, генерацию и подготовку данных выполняет другой участник. Для подключения его работы определены только форматы обмена. Старый набор задержек из `data-project` не читается и не преобразуется.

Все новые материалы находятся внутри `architecture`. Каталоги `main` и `data-project` сохранены без изменений. Ветка `architecture-design` создана от локального состояния `data-project`, коммит `0f69a87145626bfcb01e57b96ad2486080ce555a`, чтобы сохранить существующую структуру. Эта работа добавляет только каталог `architecture`; слияние в `main` выполняется отдельно.
