# Архитектура проекта СМ7

Программа должна выбирать один из трёх светофоров по истории плотности потока за последний час. Здесь собраны архитектура, реализация GRU, обоснование выбора модели, графический интерфейс и модуль синтетических данных. Основа — версия 2 ТЗ, переданная 25 ноября 2026 года.

## Начать работу

В Windows дважды нажмите **START.cmd**. Откроется окно с кнопками. Среда Python 3.12 и необходимые библиотеки проверяются автоматически. При первом запуске на другом Windows ПК программа скачает недостающие компоненты; для этого нужен интернет. Последующие запуски с исправной средой не обращаются в сеть.

В окне доступны проверка GRU, объяснение выбора модели, схема и состояние проекта. Проверка выполняет один технический шаг обучения и проверяет сохранение и загрузку весов в памяти. Она не использует дорожные данные и не создаёт обученную модель проекта. Генерация и подготовка данных доступны через консольные команды и меню.

Схему можно открыть и отдельно: [docs/overview.html](docs/overview.html).

В Ubuntu или из терминала Windows, из каталога `architecture`:

```text
python run.py
python run.py architecture
python run.py model
python run.py status
python run.py status --json
python run.py gui
python run.py verify-model
```

В Ubuntu команда интерпретатора может называться `python3`.

Для модуля данных:

```text
python -m pip install -r requirements-data.txt
python run.py generate
python run.py validate
python run.py prepare
python -m unittest discover -s tests -v
```

Данные и их конфигурация находятся в `data/`. После `prepare` формируются отчёт `results/data_report.json` и контрольный вход `data/control/history.csv` без будущей строки. Полное описание — в [инструкции по подготовке данных](docs/data-preparation.md). Для модуля данных нужен NumPy, для проверки GRU — PyTorch. Обучение на полном наборе, оценка и рабочий прогноз пока не подключены: соответствующие команды возвращают объяснение и код 2, а не фиктивный результат. В графическом интерфейсе эти действия отключены до интеграции.

## Границы текущей работы

Генерация, валидация и подготовка окон реализованы в `src/sm7/data_adapter.py`; интерфейс совместим с архитектурой. Старый набор задержек из `data-project` не читается и не преобразуется. GRU реализована; обучение на подготовленных данных, оценка и прогноз остаются отдельными задачами команды.

Все новые материалы находятся внутри `architecture`. Каталоги `main` и `data-project` сохранены без изменений. Исходная ветка `architecture-design` была создана от локального состояния `data-project`, коммит `0f69a87145626bfcb01e57b96ad2486080ce555a`. Дополнение модуля данных основано на объединённой версии `main` с архитектурой; слияние выполняется отдельно через Pull Request.

За архитектуру и реализацию GRU ответственный Борис.
