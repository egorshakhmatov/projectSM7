# Архитектура проекта СМ7

Программа должна выбирать один из трёх светофоров по истории плотности потока за последний час. Здесь собраны архитектура, обоснование модели, запускаемый каркас и реализованный модуль синтетических данных. Основа — версия 2 ТЗ, переданная 25 ноября 2026 года.

## Начать работу

В Windows дважды нажмите **START.cmd**. Нужен Python 3.12. Откроется консольное меню, из которого можно посмотреть схему, прочитать объяснение модели, проверить состояние проекта, сгенерировать, проверить и подготовить данные. Схема доступна и без Python: откройте [docs/overview.html](docs/overview.html) обычным браузером.

В Ubuntu или из терминала Windows, из каталога `architecture`:

```text
python run.py
python run.py architecture
python run.py model
python run.py status
python run.py status --json
```

В Ubuntu команда интерпретатора может называться `python3`.

Для модуля данных:

```text
python -m pip install -r requirements-data.txt
python run.py generate
python run.py validate
python run.py prepare
python -m unittest discover -s tests -v
```

Данные и их конфигурация находятся в `data/`. После `prepare` формируются отчёт `results/data_report.json` и контрольный вход `data/control/history.csv` без будущей строки. Полное описание — в [инструкции по подготовке данных](docs/data-preparation.md). Меню и материалы работают без интернета и сторонних библиотек; для модуля данных нужен NumPy. Обучение, оценка и прогноз пока не подключены: соответствующие команды возвращают объяснение и код 2, а не фиктивный результат.

## Границы текущей работы

Генерация, валидация и подготовка окон реализованы в `src/sm7/data_adapter.py`; интерфейс совместим с архитектурой. Старый набор задержек из `data-project` не читается и не преобразуется. Модель GRU, обучение, оценка и прогноз остаются отдельными задачами команды.

Все новые материалы находятся внутри `architecture`. Каталоги `main` и `data-project` сохранены без изменений. Исходная ветка `architecture-design` была создана от локального состояния `data-project`, коммит `0f69a87145626bfcb01e57b96ad2486080ce555a`. Дополнение модуля данных основано на объединённой версии `main` с архитектурой; слияние выполняется отдельно через Pull Request.
