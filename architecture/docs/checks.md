Четыре автоматические проверки запускаются командой `.venv\Scripts\python.exe -m unittest discover -s tests -v` из каталога architecture. Технический тест не читает и не создаёт учебные данные, не сохраняет рабочие веса проекта и не оценивает качество прогноза.

Установка Python на полностью чистый ПК, автоматическая установка всех библиотек именно подготовщиком при пустой среде и запуск Ubuntu ещё не проверены. На текущем ПК библиотеки первоначально установлены напрямую в `.venv`, затем успешно проверены обычный путь запуска и автоматическая установка недостающей зависимости подготовщиком.
