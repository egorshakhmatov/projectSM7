# Проверки проекта

Для подготовки данных достаточно Python 3.12 (стандартная библиотека). Проверяется формат CSV из семи полей, 70 176 строк, хронологический шаг 15 минут, неотрицательные конечные значения, выборки, происхождение наблюдений и состав окон.

```bash
python run.py validate
python run.py prepare
python run.py status --json
python -m unittest discover -s tests -v
python run.py verify-model
```

Технические тесты GRU проверяют форму [N,8,3] → [N,3], неотрицательность результата, изменение весов на одном техническом шаге и идентичность прогноза после сохранения и загрузки. Они требуют PyTorch; если он отсутствует, соответствующие unittest-тесты пропускаются с явным сообщением. Для запуска GUI используется специально подготовленная среда.

Исторический протокол от 25 ноября для прежней задачи классификации плотности доступен в [истории Git](https://github.com/egorshakhmatov/projectSM7/tree/1d1494e58439ff035821e408c2790c523bb87380/architecture/docs). Он не является проверкой новой постановки. Полноценное обучение и метрики качества ещё не выполнены.
