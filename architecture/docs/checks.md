# Проверки архитектурного каркаса

Проверено 25 ноября 2026 года на Windows с Python 3.12.10. Этот протокол относится только к архитектуре и запуску; качество модели и приёмочные проверки полной программы ещё не оценивались.

| Проверка | Результат |
|---|---|
| Синтаксис run.py и чтение config.json | Пройдено |
| Расчёт числа параметров по размерам весов | 3 651 для выбранной GRU с выходным слоем |
| status и status --json | Пройдено; прогноз явно недоступен |
| Вывод объяснения модели и справки команд | Пройдено |
| Запуск без интерактивного ввода | Пройдено; выводится состояние без зависания |
| Зарезервированные режимы generate, prepare, train, evaluate, predict | Пройдено; объяснение и код 2 |
| Неизвестная команда | Пройдено; код 2 |
| START.cmd из другого рабочего каталога | Пройдено; путь проекта содержит пробелы и кириллицу |
| Локальные ссылки документов, якоря HTML и синтаксис SVG | Пройдено |
| Изменения существующих каталогов main и data-project | Отсутствуют |

Визуальный просмотр HTML через автоматизированный браузер не выполнен: средство просмотра блокирует локальные file URL. Схему можно открыть вручную через `docs/overview.html`.

Интерактивное меню в отдельном окне, открытие браузера из меню, обучение PyTorch, сохранение и загрузка весов и запуск на Ubuntu требуют последующей проверки. PyTorch на этой машине не установлен; каркас его не использует. Измеренные метрики и обученные веса в текущую поставку не входят.
