Два независимых сценария

Сначала модель обучают и сохраняют. Затем её используют многократно без повторного обучения.

Данные подготовлены в единственной папке data-project. Проверка и формирование окон подключены.

Выбрана GRU с памятью из 32 чисел

GRU читает наблюдения по порядку и обновляет внутреннюю память. После последнего наблюдения память преобразуется в три прогноза задержки в минутах.

8 × 3 задержки→Задержки в минутах→GRU 32→Linear 32 → 3→Softplus и минимум

Соответствует задаче

Обрабатывает восемь наблюдений. Ответ — три прогнозируемые задержки через 60 минут.

Компактная структура

Один слой GRU и выходной слой: 3 651 обучаемый параметр. У LSTM того же размера — 4 835 параметров.

Качество проверим

Сравнение с минимумом последней строки по MAE, доле верного выбора и дополнительной задержке. Преимущество GRU заранее не известно.

Во время обучения MSELoss сравнивает прогнозируемые и фактические задержки. При равенстве минимума выбирается первое направление.

Подробности: обоснование модели. Первичные источники: PyTorch GRU, PyTorch LSTM, MSELoss.

Сейчас

Двойной щелчок по START.cmd подготавливает среду и открывает окно с кнопками. Доступны проверка GRU, схема, объяснение модели и состояние.

После подключения

В то же меню добавятся обучение, оценка и прогноз. Обычному пользователю не придётся запоминать команды.

Локально на ПК

Python 3.12, PyTorch и CPU. Данные, модель и результаты — в отдельных папках. Работа после установки автономная.

Отдельные команды сохраняются для повторяемых проверок. Прогноз использует готовые веса; обучение выполняется только по явной команде пользователя.
