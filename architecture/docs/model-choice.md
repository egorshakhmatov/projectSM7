# Почему GRU

Задержки зависят от истории дорожной ситуации. GRU обрабатывает наблюдения по порядку и обновляет скрытое состояние, позволяя учитывать развитие затора. Вход — восемь значений задержек по направлениям A/B/C с интервалом 15 минут. Задача — регрессия: три задержки через 60 минут.

| Компонент | Размер |
|---|---|
| Вход | [batch,8,3] |
| GRU | Один слой, 32 скрытых признака |
| Linear | 32 → 3 |
| Softplus | Неотрицательные задержки в минутах |
| Выход | [batch,3] |

Модель имеет 3 651 обучаемый параметр: 3 552 у GRU и 99 у линейного слоя. Изменение длины окна не меняет их число. Сопоставимая LSTM — 4 835 параметров. Обучение планируется на CPU; MSELoss сравнивает три прогнозируемых и фактических задержки, Adam обновляет веса. Настройки — в `config.json`.

Базовый алгоритм: сохранить последние три задержки без изменения; выбрать минимальную. Качество GRU определяется сравнением на отложенном test, а не объявляется заранее. При равном прогнозируемом минимуме выбирается A, затем B, затем C.

Справка: [PyTorch GRU](https://docs.pytorch.org/docs/stable/generated/torch.nn.GRU.html), [MSELoss](https://docs.pytorch.org/docs/stable/generated/torch.nn.MSELoss.html), [Softplus](https://docs.pytorch.org/docs/stable/generated/torch.nn.Softplus.html).
