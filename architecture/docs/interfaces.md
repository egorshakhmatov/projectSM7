# Соглашения между модулями

Актуальный источник: `../data-project/traffic_delays.csv`, 70 176 строк, 7 полей. Время ISO 8601 с UTC-смещением; шаг 15 минут в UTC. Описание происхождения и календарных признаков — в [data-project/README.md](../../data-project/README.md).

## Интерфейс подготовки

Из `architecture` можно подключить единственный адаптер:

```python
import sys
from pathlib import Path
sys.path.insert(0, str(Path.cwd().parent / "data-project"))
from prepare_data import load_split
X, y, source = load_split("train")
```

После преобразования в torch.float32: X имеет вид [N,8,3], y — [N,3], исходные единицы — минуты. Столбцы A/B/C. Нормализация на 200 не применяется. Метки источника не являются входным признаком; календарные поля пока доступны в CSV, но не входят в текущий тензор. Разбиение хронологическое и не пересекает смены источника. Размеры: 45 040 train, 9 746 validation, 9 852 test. Окно включает моменты t−105, …, t; y соответствует t+60 минут.

## Модель

`TrafficGRU.forward(X)` → три неотрицательных прогнозируемых задержки [N,3]. Выбирается индекс минимальной задержки (A, B, C). Для обучения используется MSELoss по трём значениям, не CrossEntropyLoss. Техническая проверка не заменяет обучение на данных.

## Форматы будущих результатов

Метаданные весов должны включать версию формата, конфигурацию входа/выхода, эпоху, потерю на validation, контрольную сумму CSV, версии библиотек. Старые веса классификации несовместимы с новой постановкой.

Прогноз (формат, иллюстрация, не измеренный результат):

```json
{
  "forecast_origin": "2025-07-04T09:00:00-05:00",
  "target_time": "2025-07-04T10:00:00-05:00",
  "predicted_delays_minutes": [1.2, 0.8, 2.0],
  "selected_light": "B"
}
```

Итоговая оценка: MAE трёх задержек, доля верного выбора минимального фактического ожидания, среднее дополнительное ожидание выбранного направления. Оба алгоритма оцениваются на одних и тех же test-окнах; при равенстве фактических минимумов любой минимум считается верным. Дополнительно полезно разделить метрики по происхождению строк.

`validate` и `prepare` не изменяют данные; ошибки приводят к ненулевому коду. `train`, `evaluate`, `predict` пока не реализованы.
