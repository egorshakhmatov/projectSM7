# Прогноз задержек у трёх светофоров

Учебный проект нашей группы.

Программа анализирует историю задержек у трёх светофоров,
прогнозирует задержки через 60 минут и рекомендует светофор
с минимальным прогнозируемым ожиданием.

## Данные

- Период наблюдений: два года.
- Шаг наблюдений: 15 минут.
- Задержки измеряются в минутах.

## План работы

1. Подготовить и проверить данные.
2. Реализовать базовый алгоритм.
3. Обучить нейросеть.
4. Сравнить результаты.
5. Подготовить инструкцию запуска.
