# Подготовка данных для прогноза задержек у светофоров

Цель этой ветки — подготовить данные для обучения, валидации и тестирования модели. По восьми последним наблюдениям модель прогнозирует задержки у светофоров A, B и C через 60 минут. Программа рекомендует направление с наименьшей прогнозируемой задержкой.

## Исходные данные

Первый набор находится в файле `traffic_delays.xlsx`. В нём **70 176 строк за 2024–2025 годы** с шагом **15 минут**. Время указано в UTC, задержки — в минутах.

- **30% строк** — задержки, рассчитанные по опубликованным скоростям на трёх участках Чикаго. Прямых замеров ожидания у стоп-линии в наборе пока нет.
- **70% строк** — синтетические данные с различиями между направлениями, буднями и выходными, а также с суточными колебаниями и кратковременными заторами.

Таблица разделена по времени на листы `train` (70%), `validation` (15%) и `test` (15%). Соотношение 30/70 описывает происхождение данных, а 70/15/15 — их назначение.

## Как формируем обучающий пример

Вход `X` — восемь последовательных наблюдений с задержками A, B и C. Ответ `y` — три задержки через четыре строки после последнего наблюдения. Например, если история заканчивается в **12:00**, ответ берём из строки на **13:00**.

Для построения примеров используем только моменты с `window_ok = 1`. Это означает, что история и ответ находятся в одной выборке и относятся к одному источнику. На вход модели подаются только столбцы `delay_A`, `delay_B`, `delay_C`.
